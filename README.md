# Pinyin Studio

Extension de navigateur pour apprendre le mandarin : sous-titres pinyin et doublage des vidéos YouTube,
dictionnaire personnel et quiz espacés corrigés par IA.

- **Politique de confidentialité** : https://cj-19.github.io/pinyin-studio/privacy.html
- **Télécharger l'extension** (Chrome, Brave, Opera, Vivaldi, en mode développeur) : voir les
  [versions publiées](https://github.com/cj-19/pinyin-studio/releases).
- **Questions et problèmes** : [ouvrir un ticket](https://github.com/cj-19/pinyin-studio/issues).
